# 過去の追加申請の取り込み（一時的）

Google フォームで受け付けていた過去の絵文字の追加申請のうち、**今はまだ無い絵文字**を、アプリ内の追加申請（審査待ち）として取り込むための手元用の道具。

移行が終わったら、このディレクトリと `packages/backend/src/server/api/endpoints/admin/emoji-add-request/import-legacy.ts`（と `endpoints.ts` の登録）を削除する。

## 手順

1. **フォームの受付を止める**（止める前に取り込むと、その後の申請が漏れる）
2. **回答シートを書き出す**
   スプレッドシート「絵文字申請」を開き、［ファイル］→［ダウンロード］→［カンマ区切り形式（.csv）］で保存し、`input/sheet.csv` に置く。
   メールアドレスとトークンの列を含むので、`input/` は git に入れない（`.gitignore` 済み）。
3. **申請チャンネルのノートを書き出す**（本番 DB。読み取りのみ）
   `notes.sql` の結果を `input/notes.json` に保存する。
   ```sh
   psql -X -A -t -f notes.sql > input/notes.json
   ```
4. **候補を作る**
   ```sh
   node scripts/emoji-legacy-import/build.mjs
   ```
   `output/candidates.md` で、取り込む候補と除いたもの（理由つき）を確かめる。
5. **取り込む**
   管理者のアカウントで API コンソール（`/api-console`）を開き、エンドポイントに `admin/emoji-add-request/import-legacy`、パラメータに `output/payload.json` の中身を貼って送る。
   結果の `created` が取り込んだもの、`skipped` が飛ばしたもの（理由つき）。同じ内容を 2 回送っても、取り込み済みのものは飛ばされる。
6. **審査画面で確かめる**
   `/admin/emoji-requests` の審査待ちに並ぶ。申請の出どころは「Google フォームから移行」と表示される。

## 取り込みの決まり

| 項目 | 内容 |
| --- | --- |
| 対象 | 同じ名前のローカル絵文字が今は無いもの |
| 対応づけ | 申請チャンネルの「この絵文字を登録する(id:N)」のノートの `row=N` が、回答シートの N 行目（見出しが 1 行目） |
| 画像 | 申請チャンネルのノートに添付された画像を、サーバー側へ複製して使う |
| 申請者 | ノート本文の「申請者 @ユーザー名」。ローカルユーザーが見つからなければ無し |
| 重複 | 同じ名前・同じ申請者なら、いちばん新しい 1 件だけ |
| 許可の後、コピー可 | フォームでは使用情報の欄が連絡先だったので、連絡先として取り込む |
| モチーフ | 旧フォームには質問が無かったので「いいえ」（文字だけの絵文字は無し）。審査画面で直せる |
| 通知 | 送らない |
